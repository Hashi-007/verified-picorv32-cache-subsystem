# Authorship and third-party code

This is a guided RTL and design verification portfolio project by
**Muhammad Hashir Aslam**.

## Project contributions

The learner developed the cache RTL, initial wrapper connections, verification
exercises and program loops through guided implementation and review.
Mentor assistance includes architecture explanations, starter scaffolding,
review corrections, integration fixes, verification consolidation, program
setup and instruction encoding, instrumentation, runners and reports.
Repository preparation, documentation and source cleanup were also assisted.

The project demonstrates the resulting implementation and measured behavior;
it does not claim that every file was written independently. The local
learning history and pre-edit snapshots are retained outside the publication
archive.

## PicoRV32

The processor is existing **PicoRV32** IP by Clifford Wolf and contributors.
This project integrates that CPU with the cache subsystem; it does not claim
authorship of the CPU.

- Upstream: https://github.com/YosysHQ/picorv32
- Revision: `ef203c2b0a3fb793280f5114941416c425c5b461`

- Provenance and source hashes: [UPSTREAM.md](third_party/picorv32/UPSTREAM.md).

The original CPU source and license are unmodified.
